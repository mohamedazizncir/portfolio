## Agentic orchestration framework benchmark

Comparative benchmarking study of agentic AI orchestration frameworks: LangGraph, CrewAI, AG2/AutoGen, and the OpenAI Agents SDK.

Built a minimal two-agent sequential pipeline as a consistent test harness across all frameworks, using a local Ollama model (qwen2.5:7b) so the comparison was not affected by different model quality. Used separate virtual environments per framework to avoid dependency conflicts.
