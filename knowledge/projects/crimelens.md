## CrimeLens

Full-stack crime hotspot analytics platform, built on Chicago's open crime data (via the Socrata API) combined with US Census ACS data.

**Stack:** H3 hexagonal spatial grids for aggregation, XGBoost for prediction, FastAPI backend, React frontend with Mapbox GL JS for the map view.

**Status:** ran end to end successfully. Along the way, resolved Python 3.14/Windows pandas compatibility issues and virtual environment management problems.
